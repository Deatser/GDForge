# Changelog

## v0.4.1
- Windows are listed with their labels and titles

## v0.4.0
- The game's windows can be used like by hand: trigger settings, Edit Object, Edit Group, Edit Special, HSV, the pause menu and anything they open. Buttons, checkboxes, text fields and sliders are listed with their labels, and can be clicked, set, typed into and moved; the screen can be tapped and dragged

## v0.3.3
- Zooming during a playtest; the background and ground follow a view held on a point

## v0.3.2
- Automated tests in platformer: left, right and jump at set times; the path is recorded by time
- The view can stay on a point during a playtest, and Hide Invisible can be switched
- Objects read during a playtest report where they are, not where they started
- Colour triggers keep the opacity they are placed with
- Level settings report the song; changing the art redraws it at once

## v0.3.1
- Legacy Options; the editor no longer opens while the game is loading

## v0.3.0
- Level settings, start colours and the game's own songs

## v0.2.0
- Playtests, screenshots, saving, songs, ASCII map
